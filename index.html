CONFERENCE PUBLICATION • LOW-LATENCY SYSTEMS DEFENSE
HINWEIS FIFTH INTERNATIONAL CONFERENCE ON ADVANCES IN SOFTWARE ENGINEERING AND INFORMATION TECHNOLOGY (ASIT-2026)

In-Kernel Defense: Low-Latency In-Kernel Ransomware Containment with eBPF

Research paper approved and presented at ASIT-2026. Investigates kernel-space mitigation strategies using eBPF to circumvent the user-space latency penalties that cause massive data loss during active ransomware encryption bursts.

01. Behavioral Kernel Interception

Hooks eBPF kprobes directly to sys_enter_write and sys_enter_openat to monitor file modification velocity and suspicious descriptor access patterns at line rate with near-zero CPU overhead.

02. Shannon Entropy Profiling

Executes real-time entropy estimation over file write buffers directly inside the kernel, differentiating routine data compression from malicious cryptographic ransomware routines when entropy exceeds 7.8 bits/byte.

03. Automated SIGSTOP Containment

Dispatches SIGSTOP process suspension directly from kernel space within sub-millisecond intervals, freezing offending processes before bulk encryption can persist to disk.
