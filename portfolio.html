In-Kernel Defense: Low-Latency In-Kernel Ransomware Containment with eBPF

Research paper approved and presented at ASIT-2026. Investigated kernel-space mitigation strategies to circumvent the user-space latency penalties that cause massive data loss during active ransomware encryption bursts.

01. Behavioral Kernel Interception

Leveraged eBPF kprobes attached directly to sys_enter_write and sys_enter_openat to monitor I/O velocity and suspicious file descriptor access patterns with negligible CPU overhead.

02. Shannon Entropy Profiling

Executed real-time entropy estimation algorithms over file write buffers directly inside the kernel, differentiating routine document compression from malicious cryptographic encryption routines.

03. Automated SIGSTOP Containment

Architected an autonomous kernel-level process suspension pipeline, dispatching SIGSTOP to offending PIDs in sub-millisecond timeframes without relying on sluggish user-space telemetry loops.
